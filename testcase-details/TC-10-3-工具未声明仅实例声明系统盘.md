# TC-10-3 工具未声明系统盘，仅实例声明

| 项 | 值 |
|---|---|
| 用例编号 | TC-10-3 |
| 所属测试例 | TC-10 系统盘真实生效验证 |
| 优先级 | P1 |
| 类型 | 正向 / 边界 |
| 结论 | **PASS** |

## 测试目的

验证工具层面完全不声明 `Storage` 时，是否仍可通过实例级声明指定系统盘。

## 测试步骤

1. `CreateSandboxTool`，`Resources` **只传 CPU 和 Memory**，不传 `Storage`
2. 等工具 `ACTIVE`，回查工具配置中 `Storage` 为空
3. `StartSandboxInstance` 时传 `Resources={CPU, Memory, Storage: 30Gi}`
4. 进沙箱 `df` 量根分区

## 实际结果

| 检查项 | 值 |
|---|---|
| 工具回查 Storage | 空（未声明） |
| 实例回显 | 30Gi |
| 沙箱内实测 | 29.36Gi（-2.1%） |
| 结论 | **PASS** |

**结论：工具不声明时，实例级声明完整生效，无需先在工具上设置默认值。**
