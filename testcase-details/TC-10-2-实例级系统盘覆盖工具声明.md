# TC-10-2 实例级系统盘覆盖工具声明

| 项 | 值 |
|---|---|
| 用例编号 | TC-10-2 |
| 所属测试例 | TC-10 系统盘真实生效验证 |
| 优先级 | P0 |
| 类型 | 正向 / 优先级 |
| 结论 | **PASS** |

## 测试目的

验证 `StartSandboxInstance` 传入的 `CustomConfiguration.Resources.Storage`
会覆盖工具级声明，且**只对本次实例生效**，不影响工具本身。

## 测试步骤

1. `CreateSandboxTool`，工具声明 `Storage=20Gi`
2. 等工具 `ACTIVE`，回查工具配置确认 `20Gi`
3. `StartSandboxInstance` 时传 `Resources={CPU, Memory, Storage: 50Gi}`
4. 等实例 `RUNNING`
5. 进沙箱 `df` 量根分区，应为 ~50Gi
6. 回查工具配置，应仍为 `20Gi`（未被修改）

## 实际结果

| 检查项 | 值 | 结论 |
|---|---|---|
| 工具声明 | 20Gi | — |
| 工具回查 | 20Gi | 未被实例覆盖 ✅ |
| 实例回显 | 50Gi | 覆盖生效 ✅ |
| 沙箱内实测 | 48.91Gi | 与 50Gi 一致（-2.2%） ✅ |

**结论：实例级声明优先于工具级声明，且不污染工具配置。**

## 备注

覆盖 `Resources` 时 **CPU 和 Memory 必须一并填写**，否则报
`Resources: CPU is required; Memory is required`（见 TC-10-4）。
